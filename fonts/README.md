# 나눔고딕 글꼴

`NanumGothic.ttf`와 라이선스 원문 `OFL.txt`를 함께 제공합니다. 앱은 이 폴더의 파일만 사용하며 운영체제에 설치된 한글 글꼴에 의존하지 않습니다.

다시 내려받을 때:

1. [Google Fonts의 나눔고딕 원본](https://github.com/google/fonts/blob/main/ofl/nanumgothic/NanumGothic-Regular.ttf)을 엽니다.
2. 원본 파일 내려받기 버튼으로 TTF를 다운로드합니다.
3. 파일 이름을 `NanumGothic.ttf`로 바꿉니다. 확장자가 두 번 붙지 않았는지 확인합니다.
4. `app.py` 옆의 `fonts` 폴더에 넣습니다.
5. [OFL 원문](https://github.com/google/fonts/blob/main/ofl/nanumgothic/OFL.txt)도 같은 폴더에 보관합니다.
