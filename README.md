# 우리말 데이터 탐구실

초등수학영재프로그램개발 대학원 강좌를 위한 한국어 텍스트 분석 실습 앱입니다. Python과 Streamlit으로 만들었으며 앱 코드는 `app.py` 하나에 있습니다.

## 1. 내 컴퓨터에서 실행

1. Python 3.12 이상을 설치합니다. 처음 설치하는 Windows 사용자는 설치 화면에서 Python을 경로에 추가하는 옵션을 선택합니다.
2. 이 폴더 전체를 내려받아 압축을 풉니다. 아래 구조를 유지합니다.

```text
app.py
requirements.txt
README.md
fonts/
  NanumGothic.ttf
  OFL.txt
  README.md
.streamlit/
  config.toml
```

3. `app.py`가 있는 폴더에서 터미널을 엽니다. Windows에서는 폴더 주소창에 `powershell`을 입력하면 됩니다.
4. 다음 명령을 한 줄씩 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS·Linux에서는 다음과 같이 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

5. 브라우저가 열리면 실습을 시작합니다. 자동으로 열리지 않으면 터미널에 표시된 로컬 주소를 엽니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

가상환경을 쓰지 않는 기존 Python 환경이라면 `pip install -r requirements.txt`와 `streamlit run app.py`로 실행할 수도 있습니다. 첫 설치에는 한국어 분석 모델 다운로드가 포함되어 시간이 걸립니다.

## 2. GitHub와 Streamlit Community Cloud에 무료 배포

1. GitHub 계정을 만들고 로그인합니다.
2. 새 저장소를 만듭니다. 학생들이 자유롭게 접속하는 수업용이라면 공개 저장소로 시작하면 편합니다. 학생의 실제 글은 저장소에 올리지 않습니다.
3. 파일 업로드 기능으로 `app.py`, `requirements.txt`, `README.md`, `fonts` 폴더와 `.streamlit` 폴더를 올립니다. `app.py`가 저장소 최상위에 있어야 합니다. `.venv`, `work`, 개인 입력 파일은 올리지 않습니다.
4. 저장소 화면에서 `fonts/NanumGothic.ttf`와 `fonts/OFL.txt`가 보이는지 확인하고 변경 사항을 저장합니다.
5. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속해 GitHub 계정으로 로그인하고 저장소 접근을 연결합니다.
6. 앱 생성 메뉴인 **Create app**을 선택하고 GitHub 저장소에서 배포하는 항목으로 들어갑니다.
7. 저장소, 브랜치(보통 `main`), 실행 파일 경로 `app.py`를 지정합니다.
8. 고급 설정에서 Python 3.12 이상을 선택합니다. 이 앱에는 API 키나 비밀 설정이 필요하지 않습니다.
9. **Deploy**를 누르고 의존성 설치와 앱 시작을 기다립니다.
10. 배포가 끝나면 발급된 `https://…streamlit.app` 주소를 복사합니다. 비로그인 창에서도 접속되는지 확인합니다. 접근 제한을 사용했다면 학생에게 보기 권한을 부여합니다.
11. 이후 코드를 고칠 때는 GitHub의 파일을 수정하고 저장합니다. Cloud에서 변경 사항이 반영되는지 확인합니다.

메뉴 이름은 서비스 개편에 따라 조금 달라질 수 있습니다. [공식 배포 안내](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)를 참고하세요. 무료 환경의 자원 제한 때문에 여러 학생이 동시에 긴 글을 분석하면 대기할 수 있습니다. 수업 전에 실제 예상 인원으로 접속해 보세요.

## 3. 수업에서 학생들이 사용하는 방법

1. 교사가 배포 주소를 LMS·학급 게시판·발표 자료에 공유합니다.
2. 학생은 브라우저에서 링크를 엽니다. 학생 컴퓨터에 Python을 설치할 필요가 없습니다.
3. 먼저 영화 댓글 예시를 불러오고 분석합니다. 청바지 예시를 선택하면 문서 나누기와 해당 품사 선택이 함께 설정됩니다.
4. 형태소 분리 결과를 펼쳐 원문과 어간·품사를 비교합니다. 불용어가 왜 필요한지 토론합니다.
5. 표의 포함 체크를 바꾸고, 같은 뜻으로 묶을 단어의 이름을 같게 고칩니다. 아래 합산 결과와 시각화가 즉시 반영됩니다.
6. 청바지 예시에서 TF·DF·IDF를 비교합니다. ‘모든 문서에 흔한 단어’와 ‘한 문서에 특징적인 단어’가 어떻게 다른지 살펴봅니다.
7. 빈도와 TF·IDF 워드클라우드를 비교하고 PNG 또는 엑셀로 내려받아 과제를 제출합니다.

## 4. 계산과 편집 규칙

- 분석은 **분석하기**를 눌렀을 때만 실행됩니다. 색상·슬라이더·다운로드·표 편집으로 형태소 분석이 다시 실행되지 않습니다.
- 입력과 분석 옵션을 바꾸면 이전 결과라는 안내가 나타납니다. 다시 분석하면 기존 표 편집은 초기화됩니다.
- `NNG`, `NNP`가 기본 선택됩니다. `VV`, `VA`는 어간 뒤에 ‘다’를 붙이고 그 뒤에 불용어를 적용합니다. 한 글자 제외도 표시 단어 기준입니다.
- 사용자 사전은 `add_user_word(단어, "NNP", 10.0)`로 등록합니다. 고유명사 선택을 켜야 결과에 포함됩니다. 등록한 단어는 같은 세션에서 유지되므로 입력 상자에서 지워도 기존 등록이 취소되지는 않습니다. 브라우저 새로고침으로 세션을 새로 시작하면 초기화됩니다.
- Kiwi는 `st.cache_resource(scope="session")`로 세션당 한 번 생성합니다. 다른 학생의 사용자 사전과 섞이지 않습니다. `cong` 모델과 작업자 하나를 사용합니다.
- 빈도·품사·상대도수는 읽기 전용이며 포함 여부와 단어 이름을 편집합니다. 같은 이름으로 바꾼 **포함된 행**만 합산합니다. 원본 행은 수정·제외를 되돌릴 수 있도록 편집표에 남고, 바로 아래 결과표와 모든 그림에는 합산된 값이 쓰입니다.
- 전체 단어 수는 품사·불용어·한 글자 필터를 적용한 뒤의 출현 횟수입니다. 서로 다른 단어 수는 현재 포함·이름 합산 후의 종류 수입니다. 제외한 단어 수는 체크를 끄거나 빈 이름으로 만든 편집표 행 수입니다.
- 상대도수 = 해당 빈도 ÷ 분석 조건 적용 후 전체 출현 횟수입니다. 단어를 제외하면 표시된 상대도수의 합은 1보다 작을 수 있습니다.
- ‘상위 N개만 포함’은 수정한 이름별 합계 순으로 선택합니다. 빈 이름은 제외합니다. 모두 포함은 빈 이름을 제외한 행을 다시 포함합니다.
- TF는 문서 내 원시 출현 횟수입니다. DF는 해당 단어가 등장하는 문서 수, N은 빈 문단을 제외한 전체 문서 수입니다. 분석 대상 단어가 없는 문서도 N에는 포함합니다.
- IDF는 `N/DF` 또는 자연로그 `ln(N/DF)`이며 스무딩을 넣지 않습니다. 이름을 합치면 문서별 빈도를 합친 뒤 DF를 다시 계산합니다.
- 문서별 TF·IDF 표는 동률인 최댓값을 모두 강조합니다. 행 전체가 0이면 그 행 전체가 동률입니다. 로그식의 가중치가 전부 0일 때는 설명을 띄우고 빈도나 교과서식으로 전환하도록 안내합니다.
- TF·IDF 워드클라우드는 전체 문서 가중치의 합 또는 선택한 문서의 가중치를 사용합니다.
- CSV는 현재 포함·합산된 결과, 엑셀은 합산 결과·편집표와 문서별 계산표를 담습니다. CSV는 UTF-8 BOM을 사용합니다. 수식으로 오해될 수 있는 CSV 단어 앞에는 작은따옴표를 넣습니다.
- PNG 마스크의 어두운 부분에 단어를 배치합니다. 흰색·투명 부분에는 배치하지 않습니다. 최대 1000×1000으로 축소합니다. 최소 글자 크기가 크면 지정한 최대 단어 수보다 적게 배치될 수 있습니다.

## 5. 입력 자료와 보관

텍스트·업로드·분석 결과·엑셀·PNG는 세션 메모리와 메모리 버퍼에서만 다룹니다. 입력을 디스크, 데이터베이스, 분석용 전역 캐시에 저장하거나 외부 분석 API로 보내지 않습니다. Cloud에서는 분석을 위해 입력이 앱 서버로 전송됩니다. 브라우저 새로고침이나 세션 종료 후 편집 결과가 유지되지 않을 수 있으므로 필요한 결과는 내려받으세요. 학생 이름 등 불필요한 개인정보는 입력하지 않는 방식으로 수업을 운영하세요.

## 6. 글꼴과 라이선스

나눔고딕 TTF를 포함했습니다. [글꼴 안내](fonts/README.md)에 재다운로드 방법과 출처가 있습니다. SIL Open Font License 1.1 원문은 `fonts/OFL.txt`이며 배포 시 함께 유지합니다. 파일이 없으면 화면에 안내하며 그림 생성을 중단합니다.

## 7. 검수 결과

검수 환경: Python 3.14, Streamlit 1.62.0, kiwipiepy 0.22.2 (`cong` 모델). Kiwi의 `JOIN_ADJ_SUFFIX` 옵션으로 ‘지루/XR + 하/XSA’, ‘저렴/XR + 하/XSA’를 형용사 어간으로 결합한 뒤 ‘다’를 붙입니다. 동사 파생 접미사 결합은 사용하지 않아 ‘추천해요’의 명사 ‘추천’을 유지합니다.

### 영화 댓글

명사·동사·형용사 포함, 기본 불용어 적용 후 실제 결과:

| 단어 | 빈도 |
|---|---:|
| 영화 | 4 |
| 감동 | 3 |
| 긴장감·눈물·보다·실망·지루하다·추천 | 각각 1 |

‘있다’, ‘없다’는 제외됩니다. ‘감동적인’은 `감동/NNG + 적/XSN + 이/VCP + ᆫ/ETM`으로 분리되어 ‘감동’으로 집계됩니다. 화면의 실제 형태소 분리 결과에서도 확인할 수 있습니다.

### 청바지 후기

문서 나누기, 명사·형용사 포함 후 실제 결과:

| 단어 | 빈도 | DF | 교과서식 IDF |
|---|---:|---:|---:|
| 청바지 | 4 | 3 | 1 |
| 추천 | 4 | 3 | 1 |
| 디자인 | 3 | 2 | 1.5 |
| 좋다 | 3 | 2 | 1.5 |
| 가격 | 2 | 2 | 1.5 |
| 예쁘다 | 1 | 1 | 3 |
| 저렴하다 | 1 | 1 | 3 |
| 신축 | 1 | 1 | 3 |

요청한 예시와 다른 부분은 ‘신축성’입니다. 이 모델은 `신축/NNG + 성/XSN`으로 분리하며, 접미사 XSN은 선택 품사에 없으므로 ‘신축’만 남습니다. 표에서 ‘신축’을 ‘신축성’으로 수정하면 빈도 1과 IDF 3이 그대로 유지됩니다. 또는 사용자 사전에 ‘신축성’을 등록하고 고유명사를 포함해 다시 분석합니다. 검수용 문장에만 맞춘 빈도 보정은 하지 않습니다.

‘추천해요’는 `추천/NNG + 하/XSV + 어요/EF`로 나뉩니다. XSV는 선택한 품사 밖이므로 제외됩니다. 독립 동사 `하/VV`가 나오는 경우에도 기본형 ‘하다’는 기본 불용어로 제거됩니다.

### 동작 검증

Streamlit AppTest로 예시 선택·분석·표 편집 이벤트·다시 배치 후 편집 유지·모두 포함·TF·IDF 전환·사각형/원/하트 그림 생성·엑셀 직렬화를 확인했습니다. 계산 함수에서는 UTF-8 BOM·CP949 읽기, 단어 이름 합산 후 DF 재계산, 제외 반영을 확인했습니다. Community Cloud에 실제 게시하는 단계는 사용자의 GitHub 계정에서 진행해야 합니다.
